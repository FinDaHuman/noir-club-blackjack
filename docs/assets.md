# Asset provenance

Built-in image generation was used for the initial complete desktop concept, the felt texture and the ornate card back. No paid image API or CLI fallback was used.

## Felt — `public/assets/felt.webp`

Final prompt: Production background texture for a premium blackjack web game. Continuous dark emerald fine wool casino felt filling all edges, seen from a gently elevated player's point of view. Fine short wool fibers, subtle worn variation, broad soft overhead light, darker corners. Color lock: #073c2f center and #03251f edges. No objects, cards, chips, table edges, rails, border, people, hands, print, text or logos. Wide landscape image, used beneath code-rendered UI.

## Card back — `public/assets/card-back.webp`

Final prompt: Production texture for the back of one luxury casino playing card. Portrait 2:3, flat orthographic edge-to-edge artwork. Deep emerald background, intricate antique muted gold guilloche filigree, thin double gold border inset 5 percent, classic gold spade in an ornamental diamond medallion. Symmetric 1920s private casino aesthetic, subtle paper texture. No perspective, shadow, surrounding surface, hands, letters, text or external white margin.

## Concept

The concept specified the entire game screen: full-bleed realistic green felt, no table edge or figures; Noir Club wordmark; dealer and player hands; curved payout printing; open session summary; bankroll, betting chips and action controls in a dark bottom strip. Ivory, evergreen and muted gold. Native UI text and interactive controls. Mobile reflow and cards always above the surface.

## Intentional native elements

Playing-card faces use accurate code-native suit/pip layouts, with stylized typographic court cards, so all ranks are legible and available to assistive technology. Casino chips use code-native material styling and denomination labels. These are intentional choices rather than generated placeholder imagery. The source artwork is preserved in the local image-generation output; only optimized WebP assets are published.
